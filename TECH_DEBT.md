# Технический долг

Реестр отложенных задач. Ведётся по ходу разработки, чтобы финальный аудит
получил готовую повестку, а не собирался по памяти.

**Правило ведения.** Сюда попадает то, стоимость чего растёт линейно.
Уязвимости, ошибки в контрактах, на которые опираются следующие этапы,
и блокирующие дефекты исправляются немедленно и в этот список не заносятся.

Статусы: `открыт` · `в работе` · `закрыт` · `отклонён`

| DI-контейнер (InversifyJS, tsyringe) | Требует `emitDecoratorMetadata` — запрещено настройкой `erasableSyntaxOnly`; тянет `reflect-metadata` в бандл рядом с ключами; переносит проверку зависимостей из компиляции в рантайм |
| Внедряемый источник случайности | Возможность подменить генератор случайных чисел означает возможность сделать все ключи предсказуемыми. Тестируемость такой цены не стоит |
| Полностью закалённый путь деривации `m/44'/60'/0'/0'/n'` | Устранил бы риск «xpub + приватный ключ», но seed-фраза перестала бы восстанавливаться в MetaMask, Trust и Ledger. Запереть пользователя в одном кошельке хуже условного риска |
| `@noble/secp256k1` отдельно от `@noble/curves` | Две независимые реализации secp256k1 в одном бандле: лишний вес и два пути исполнения для самого критичного примитива |
| Словари BIP-39 всех языков | ~55 КБ gzip ради сценария, который почти не встречается. MetaMask тоже только английский |
